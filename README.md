# Analisi Produzione Rete

Web app per analizzare la produzione della rete agenti dall'export precontratti (Excel) e verificare gli statini PDF.

Apri: https://marchesetony.github.io/analisi-produzione-rete/

I file caricati (Excel e PDF) vengono letti solo nel browser del dispositivo: non vengono inviati a nessun server.
